# FaithfulCXR

Explanation faithfulness benchmark for chest X-ray vision-language models.

This repository contains the code for the paper *Plausible but Unfaithful: 
Explanation Faithfulness in Chest X-ray Vision-Language Models*.

## Overview

FaithfulCXR evaluates whether natural language explanations generated by 
chest X-ray VLMs reflect the factors that actually drove the model's 
prediction. Three interventions are used:

- **Counterfactual test** — inject a finding absent from the image
- **Biasing test** — inject a diagnostic hint
- **Lesion masking test** — occlude the annotated lesion region

An explanation is judged *unfaithful* when the intervention changes the 
prediction but the explanation does not affirmatively mention the 
intervention factor.

```bash
git clone https://github.com/<user>/faithfulcxr.git

pip install -r requirements.txt
```

## Data

Datasets are not included. Download them separately:

- **VinDr-CXR** — https://physionet.org/content/vindr-cxr/

## Usage

Generate explanations:

```bash
python scripts/01_generate_explanations.py --limit 100
```

Run faithfulness tests:

```bash
python scripts/02_run_faith_tests.py --limit 100 \
    --tests counterfactual biasing masking
```

Evaluate plausibility:

```bash
python scripts/05_judge_plausibility.py --judge gemini \
    --judge-model gemini-2.5-flash \
    --input <explanation_file> --output <output_path>
```

Analyze:

```bash
python scripts/03_analyze.py
```

See Appendix B of the paper for the full reproduction pipeline.

## Key implementation note

Prior faithfulness work detects label mentions by string matching. This 
fails on radiology text, where negated findings are routinely enumerated 
(*"No evidence of pneumonia, pleural effusion, or cardiomegaly"*). 
`src/faithfulcxr/faith_tests/matcher.py` implements negation-scope-aware 
affirmative mention matching, which changes measured unfaithfulness by up 
to 0.45.
